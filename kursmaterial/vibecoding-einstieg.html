Vibecoding · Einstiegsroute

Dein Weg zum ersten eigenen Werkzeug mit Claude

Beim Vibecoding beschreibst du in normaler Sprache, was du willst. Claude schreibt den Code. Du testest, gibst Rückmeldung und entscheidest. Programmieren musst du nicht können. Deine Aufgabe ist, klar zu sagen, was du brauchst, und genau hinzuschauen, ob es stimmt.

Etappe 0
ca. 15 Min

Ausrüstung: Konten anlegen

Du brauchst einen aktuellen Browser (Chrome, Edge, Firefox oder Safari) und zwei Konten. Nimm für beide dieselbe E-Mail-Adresse, dann behältst du den Überblick.

Etappe 1
ca. 30 Min

Erste Schritte im Chat

Auf claude.ai kann Claude kleine Programme direkt im Chat bauen. Die heissen Artifacts und erscheinen rechts neben dem Chat. Du kannst sie sofort ausprobieren, ohne etwas zu installieren. Ideal, um das Prinzip zu lernen: beschreiben, testen, verbessern.

  1. Öffne einen neuen Chat auf claude.ai.
  2. Kopiere den Einstiegsprompt unten, ersetze den gelb markierten Teil durch deine Idee und schick ihn ab.
  3. Beantworte Claudes Fragen. Dann baut Claude eine erste Version. Probier sie aus.
  4. Gib Rückmeldung, eine Sache pro Nachricht: «Der Knopf soll grün sein», «Ich will auch ein Datum eintragen können».
Einstiegsprompt
Hallo Claude. Ich bin Einsteiger:in im Vibecoding und kann nicht programmieren. Ich möchte mit dir ein kleines, nützliches Werkzeug bauen, das als einzelne HTML-Datei im Browser läuft.

So arbeiten wir zusammen:
1. Stell mir zuerst höchstens 5 Fragen zu meiner Idee, bevor du etwas baust.
2. Schlag mir dann eine ganz einfache erste Version vor (nur das Nötigste) und warte auf mein OK.
3. Baue sie als Artifact, damit ich sie sofort ausprobieren kann.
4. Erkläre mir in 3–4 einfachen Sätzen, was du gemacht hast, ohne Fachchinesisch.
5. Sag mir nach jeder Version, was ich konkret testen soll.
6. Wenn eine Idee von mir schlecht oder zu gross ist, sag es mir ehrlich und schlag etwas Einfacheres vor.

Meine Idee: [hier in 1–3 Sätzen beschreiben, z. B. «Ein Bewerbungs-Tracker, in dem ich Firma, Datum und Status meiner Bewerbungen eintrage und sehe, wo ich nachfassen muss.»]
Merke: Gute Prompts sagen was (das Ziel), für wen (wer benutzt es) und woran du merkst, dass es fertig ist. Wie es technisch gebaut wird, darfst du Claude überlassen.
Etappe 2
ca. 30 Min

Basislager GitHub

Artifacts sind toll zum Ausprobieren. Für ein Projekt, an dem du über Tage weiterarbeitest, brauchst du einen festen Ort für deinen Code mit Versionsgeschichte. Das ist GitHub. Stell es dir als Ordner in der Cloud vor, der sich jede Änderung merkt. Geht etwas kaputt, kannst du zu einem früheren Stand zurück.

Die fünf Wörter, die du kennen musst

BegriffBedeutung im Alltag
Repository (Repo)Dein Projektordner auf GitHub, inklusive der ganzen Änderungsgeschichte.
CommitEin gespeicherter Zwischenstand mit kurzer Beschreibung, was geändert wurde. Wie ein Speicherpunkt im Spiel.
BranchEine Arbeitskopie neben der Hauptversion (main). Dort kann Claude ausprobieren, ohne das Funktionierende zu gefährden.
Pull Request (PR)Ein Antrag: «Bitte übernimm die Änderungen aus dem Branch in die Hauptversion.» Hier schaust du dir an, was sich geändert hat.
MergeDas Übernehmen. Erst nach dem Merge sind die Änderungen in main.

Dein erstes Repository

  1. Bei GitHub oben rechts auf + → New repository klicken (oder direkt github.com/new).
  2. Namen geben, kurz und ohne Leerzeichen, z. B. bewerbungs-tracker.
  3. Private wählen. Öffentlich machen kannst du es später immer noch.
  4. Häkchen bei Add a README file setzen. Dann ist das Repo nicht leer und Claude kann direkt loslegen.
  5. Create repository. Fertig, das ist dein Basislager.
Zum Vertiefen (auf Deutsch, 10 Minuten): GitHub «Hello World»-Tutorial.
Etappe 3
ca. 45 Min

Claude Code im Web

Claude Code ist Claude als Programmier-Kollege, der selbst Dateien anlegt, Code schreibt, testet und auf GitHub speichert. In der Web-Version läuft das in einem abgeschotteten Computer in der Cloud. Auf deinem Rechner wird nichts verändert. Claude arbeitet immer auf einem eigenen Branch. In die Hauptversion kommt erst etwas, wenn du es übernimmst.

  1. Öffne claude.ai/code und melde dich mit deinem Claude-Konto an.
  2. Verbinde dein GitHub-Konto, wenn du danach gefragt wirst. Erlaube der Claude-GitHub-App den Zugriff, am besten nur auf dein neues Repository («Only select repositories»).
  3. Wähle dein Repository aus und gib deinen ersten Auftrag ein (Prompt unten).
  4. Schau zu. Claude erklärt, was es tut. Am Ende liegen die Änderungen auf einem Branch, der mit claude/ beginnt.
  5. Lass Claude einen Pull Request erstellen oder klick selbst auf den entsprechenden Knopf. Auf GitHub siehst du unter Files changed genau, was neu ist. Passt alles: Merge.
Erster Auftrag im Repository
Dieses Repository ist mein erstes Vibecoding-Projekt. Ich bin Einsteiger:in und kann nicht programmieren.

Ziel: [deine Idee in 1–3 Sätzen]

Bitte so vorgehen:
1. Stell mir zuerst deine Rückfragen, falls etwas unklar ist.
2. Ergänze die README.md mit einer einfachen Beschreibung: Was ist das Projekt, wie benutzt man es.
3. Baue eine erste, einfache Version als index.html: eine einzige Datei, ohne Installation, läuft per Doppelklick im Browser.
4. Keine externen Dienste, keine Anmeldung, keine Personendaten.
5. Kleine Commits mit verständlichen Beschreibungen auf Deutsch.
6. Erkläre mir am Schluss in einfachen Worten, was du geändert hast und wie ich es teste.
Artifact aus Etappe 1 übernehmen
Ich habe im Chat auf claude.ai ein kleines Werkzeug gebaut. Den Code füge ich unten ein.
Bitte speichere ihn als index.html in diesem Repository, prüfe, ob er ohne Fehler läuft, und beschreibe in der README.md kurz, was das Werkzeug kann.
Ändere sonst noch nichts. Weitere Wünsche kommen danach einzeln.

[hier den Code aus dem Artifact einfügen: im Artifact-Fenster auf «Code» bzw. «Kopieren» klicken]

Etappe 4
ca. 20 Min

Online stellen mit GitHub Pages

Dein Werkzeug soll eine eigene Web-Adresse bekommen, die du teilen kannst? GitHub Pages stellt eine index.html gratis ins Netz, unter https://deinname.github.io/projektname.

  1. Im Repository: Settings → Pages.
  2. Bei «Source» Deploy from a branch wählen, Branch main, Ordner / (root), Save.
  3. Nach ein bis zwei Minuten erscheint oben die Adresse deiner Seite.
Achtung: Mit dem Gratis-GitHub-Konto funktioniert Pages nur für öffentliche Repositories. Dann kann die ganze Welt deinen Code und die Seite sehen. Deshalb: nichts Persönliches, keine Passwörter, keine Daten anderer Menschen ins Repo. Anleitung: GitHub Pages Schnellstart.
Etappe 5
ca. 60 Min

Auf dem eigenen Rechner: Cowork & Claude Code

Bis hier lief alles im Browser. Auf dem eigenen Rechner kann Claude direkt mit deinen Dateien und Ordnern arbeiten. Dafür gibt es zwei Wege:

WerkzeugWofürFür wen
Cowork
in der Claude-Desktop-App		Claude erledigt Aufgaben mit Dateien in einem Ordner, den du freigibst: sortieren, zusammenfassen, Tabellen und Dokumente erstellen, kleine Werkzeuge bauen.Alle, ohne Kommandozeile
Claude Code lokal
Terminal, Desktop-App oder VS Code		Software-Projekte auf deinem Rechner, mit Git und GitHub verbunden. Wie Etappe 3, nur lokal.Wer Etappe 3 gemacht hat und mehr will

Weg A: Cowork in der Desktop-App

  1. Claude-Desktop-App für Windows oder macOS herunterladen: claude.ai/download. Installieren und anmelden.
  2. Lege einen eigenen Arbeitsordner an, z. B. Dokumente/Claude-Werkstatt. Kopiere nur hinein, womit Claude arbeiten soll.
  3. In der App zu Cowork wechseln, den Ordner auswählen und die Aufgabe beschreiben (Prompt unten).
  4. Claude zeigt dir seinen Plan und fragt vor wichtigen Schritten nach. Lies die Rückfragen, bevor du zustimmst.
Start in Cowork
Ich habe dir den Ordner [Name] freigegeben.
1. Schau dir zuerst an, was darin liegt, und fasse es in ein paar Sätzen zusammen.
2. Ändere, verschiebe oder lösche nichts, ohne mich vorher zu fragen.
3. Lege neue Dateien in einem Unterordner «claude-ergebnisse» ab.

Meine Aufgabe: [z. B. «Erstelle aus meinen Bewerbungs-PDFs eine Übersichtstabelle mit Firma, Stelle, Datum und Status.»]

Weg B: Claude Code auf dem eigenen Rechner

  1. Git installieren (Windows: Git for Windows; macOS: meldet sich beim ersten Gebrauch von selbst). Empfohlen als Editor: Visual Studio Code.
  2. Claude Code installieren. Terminal öffnen (macOS: «Terminal», Windows: «PowerShell») und den passenden Befehl einfügen:
    macOS / Linux
    curl -fsSL https://claude.ai/install.sh | bash
    Windows (PowerShell)
    irm https://claude.ai/install.ps1 | iex
    Klappt etwas nicht, steht die aktuelle Anleitung im offiziellen Quickstart. Alternativ geht Claude Code auch ohne Terminal im Bereich Code der Desktop-App oder als Erweiterung in VS Code.
  3. Projekt holen: Auf GitHub im Repo auf Code → Adresse kopieren. Im Terminal:
    Repo klonen und Claude starten
    git clone https://github.com/DEINNAME/DEINPROJEKT.git
cd DEINPROJEKT
claude
    Beim ersten Start meldest du dich mit deinem Claude-Konto an.
  4. Projektregeln anlegen. Eine Datei CLAUDE.md im Projektordner liest Claude bei jedem Start. Bitte Claude, sie mit diesem Inhalt anzulegen:
    CLAUDE.md-Vorlage
    Lege bitte eine Datei CLAUDE.md mit folgendem Inhalt an:

# Projektregeln für Claude
- Ich bin Einsteiger:in. Erkläre Änderungen in einfachen Worten.
- Sprache: Deutsch, Schweizer Rechtschreibung (ss statt ß).
- Kleine Schritte: eine Änderung nach der anderen, jede als eigener Commit.
- Frag nach, bevor du Dateien löschst oder Grösseres umbaust.
- Keine Passwörter, Schlüssel oder Personendaten in Dateien schreiben.
- Sag mir nach jeder Änderung, wie ich sie teste.
Tipp: Claude Code fragt lokal vor heiklen Aktionen um Erlaubnis, etwa bevor es Befehle ausführt oder Dateien ändert. Lies diese Rückfragen. «Ja» drücken, ohne zu lesen, ist der häufigste Anfängerfehler.

Wegregeln

Wenns klemmt

Etwas funktioniert nicht? Beschreib es so, dass Claude die Ursache findet, statt zu raten. Ein Screenshot hilft oft mehr als tausend Worte. Du kannst ihn einfach in den Chat ziehen.

Etwas funktioniert nicht.
Was ich gemacht habe: […]
Was ich erwartet habe: […]
Was stattdessen passiert ist: […]
Fehlermeldung (falls vorhanden): […]

Bitte finde zuerst die Ursache und erkläre sie mir in einfachen Worten, bevor du etwas änderst.

Mini-Glossar

PromptDeine Anweisung an Claude.
ArtifactEin Programm oder Dokument, das Claude im Chat erstellt und das du direkt ausprobieren kannst.
HTMLDie Sprache, aus der Webseiten bestehen. Eine .html-Datei öffnet sich im Browser.
TerminalTextfenster, in dem man dem Computer Befehle tippt. Nur für Etappe 5B nötig.
KlonenEin GitHub-Repo auf den eigenen Rechner kopieren, inklusive Verbindung zum Original.
CLAUDE.mdNotizzettel mit Regeln, den Claude Code in jedem Projekt zuerst liest.
